# 조각조각 놀이터 — GitHub Pages용 어린이 퍼즐

- Live: https://jayersolhan.github.io/johakjogak-puzzle-pages/
- Version: v0.5 (2026-10-28)
- 퍼즐판을 화면 대부분으로 확장하고 조각 보관함에 큰 좌·우 화살표를 배치했습니다.
- 마지막으로 맞춘 조각 한 개를 되돌릴 수 있습니다. 마지막 조각을 맞춰 축하 화면이 떠도 되돌리기 가능.
- 부모가 사진을 올릴 때 자르기 영역을 손가락으로 옮기고 확대하거나, 사진 전체를 비율 유지해 맞출 수 있습니다.
- 가족 사진은 외부로 전송하지 않고 각 기기의 IndexedDB에 저장하며 다른 기기와 자동 공유되지 않습니다.
- 공개 앱에는 생성한 기본 일러스트 6종만 포함합니다. 저작권이 확인되지 않은 이미지나 가족사진을 커밋하지 마세요.

## GitHub Pages
Settings → Pages → main → / (root). 새로고침으로 업데이트 확인. 이전 저장이 남아 있으면 Safari에서 페이지를 다시 열어 확인하세요.
