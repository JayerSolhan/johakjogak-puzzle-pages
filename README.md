# 조각조각 놀이터 — 공개 웹 체험판

어린이용 직소 퍼즐 앱의 **공개 배포 전용 저장소**입니다.

- 게임 주소 (Pages가 활성화된 뒤): https://jayersolhan.github.io/johakjogak-puzzle-pages/
- 부모가 추가하는 사진 및 그림은 각 기기의 IndexedDB에만 저장되며 서버로 업로드하지 않습니다.
- 내장 일러스트 6종은 게임 체험판용으로 새롭게 생성한 그림이며 디즈니 등 기존 캐릭터 이미지는 포함하지 않습니다.
- 저작권이 확인되지 않은 이미지나 가족사진을 이 공개 저장소에 추가하지 마세요.
- 로컬 데이터는 Safari 데이터 정리 등에 의해 삭제될 수 있으며 자동 동기화되지 않습니다.

## 배포
저장소 Settings > Pages > Build and deployment > Source: Deploy from a branch > main / (root) > Save.
