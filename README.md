# 조각조각 놀이터 — 공개 웹앱

- 현재 공개 배포 버전: **v0.6.1**
- 실행 주소: https://jayersolhan.github.io/johakjogak-puzzle-pages/
- GitHub Pages: main 브랜치의 / (root)에서 배포

## v0.6.1 변경 사항

- 아이가 사용할 때 퍼즐판을 화면에 최대한 크게 표시하며 불필요한 바깥 여백을 줄였습니다.
- 조각 보관함의 페이지 화살표를 없애고 손가락 좌우 스와이프로 숨은 조각을 살펴볼 수 있습니다.
- 화면 크기에 따라 더 많은 조각을 한 번에 표시하도록 배치를 개선했습니다.
- 부모 사진의 자르기/전체 보기 선택, 한 조각 되돌리기, 기본 직소/자유형 모드는 유지합니다.
- 기존 IndexedDB 사진 및 저장 데이터를 초기화하거나 삭제하는 코드는 추가하지 않았습니다.

## 공개와 개인정보

- 이 공개 저장소에는 게임 코드와 배포용 기본 그림만 포함되어 있습니다.
- 부모가 고른 사진/디즈니 이미지/개인 사진은 저장소에 올리지 않습니다. 앱에서 선택한 사진은 각 기기 브라우저 IndexedDB에만 저장됩니다.
- GitHub Pages 웹주소와 게임 코드, 기본 그림은 누구에게나 공개됩니다.
- 기기의 브라우저 데이터를 정리하면 사진과 진행 기록이 사라질 수 있습니다.

## 테스트

- 컴퓨터 브라우저 크기에서 퍼즐 생성, 드래그, 마지막 조각 되돌리기, 가로 스와이프 동작 확인.
- 실제 iPad Safari 터치 테스트는 별도로 확인이 필요합니다.

## v0.6.1 조각 보관함 UI 보정

- 조각 뒤에 반복되던 네모 칸을 완전히 제거하고, 하나의 넓은 보관함으로 표시합니다.
- 손가락으로 밀 때는 연속 스크롤, 손을 떼면 가까운 조각 열에 정렬되어 양옆 조각이 반쯤 잘린 상태로 남지 않도록 합니다.
- 퍼즐판, 사진 자르기, 마지막 조각 되돌리기 등 기존 기능은 유지합니다.
